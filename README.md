# Bản tin sáng

Bản tin tổng hợp mỗi sáng (6:45 giờ Việt Nam) về Tài chính, Kinh tế, Bất động sản, Xu hướng AI và Công nghệ, do Claude soạn bằng tiếng Việt từ báo chí trong nước và quốc tế. Mỗi tin có link bài gốc; nội dung chưa được xác minh độc lập.

- `notes/`: từng bản tin theo ngày
- `index.json`: danh sách bản tin mới nhất, plugin Obsidian "Bản tin sáng" đọc file này để tự tải bản tin vào vault
- `scripts/publish.py`: thêm bản tin mới vào kho
